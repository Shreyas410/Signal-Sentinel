Customer Shield

Scores each incoming customer message and every link inside it, using the domain rules approved in AI Security Agent.

The link firewall checks each link's destination domain only. It never reads the message content, so it works the same for SMS, email or encrypted chat. Wording is scored separately, in memory, and nothing is stored.
